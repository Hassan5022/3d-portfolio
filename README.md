# 🚀 3D Portfolio – Hassan Ahmed

A modern, interactive developer portfolio built with **React**, **Three.js**, and animation libraries to showcase my professional experience, projects, and technical skills in a visually engaging way.

This portfolio focuses on **frontend engineering**, enterprise web applications, and interactive UI experiences, with subtle use of animations and 3D where appropriate.

---

## ✨ Features

- ⚡ Modern React-based architecture
- 🎨 Clean and responsive UI
- 🎬 Smooth animations using Framer Motion & GSAP
- 🌐 Interactive 3D elements powered by Three.js
- 📱 Fully responsive across devices
- 🔗 Live project demos with real-world applications

---

## 🛠 Tech Stack

### Frontend

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Framer Motion
- GSAP
- Three.js

### Tooling & Utilities

- Vite

- EmailJS
